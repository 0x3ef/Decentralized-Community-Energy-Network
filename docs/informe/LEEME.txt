ARCHIVO UNICO PARA TEXMAKER
La exportacion informe_texmaker.tex contiene el informe completo, incluidos
los campos de portada, capitulos y referencias. Puede compilarse por separado.
Para regenerarla desde estas fuentes:
    make archivo-unico
Resultado: build/informe_texmaker.tex

En Texmaker:
1. Abrir informe_texmaker.tex. Si hay un documento maestro anterior,
   desactivar ese modo o elegir el nuevo archivo como documento maestro.
2. Ir a Opciones > Configurar Texmaker > Comandos. En PdfLaTeX escribir:
   latex -interaction=nonstopmode -synctex=1 %.tex
3. En Compilacion rapida seleccionar PdfLaTeX + Ver PDF.
4. Compilar tres veces la primera vez para completar las referencias.
5. El resultado es informe_texmaker.pdf, junto al archivo .tex.

El boton se llama PdfLaTeX pero ejecuta el comando latex configurado.
El documento activa la salida PDF cuando latex usa pdfTeX de TeX Live.
Tambien se puede usar pdflatex directamente si esta instalado.

FUENTES POR CAPITULOS
Abrir informe.tex y mantener chapters/, referencias.tex y datos_academicos.tex
en su ubicacion. Editar datos_academicos.tex para completar la portada.
Para este formato, el documento maestro es informe.tex.

COMPILACION DESDE TERMINAL
    latex -interaction=nonstopmode -halt-on-error informe_texmaker.tex
Ejecutar tres veces en total. Para la version por capitulos:
    make COMPILADOR=latex pdf
Resultado: build/informe.pdf

PAQUETES Y FUENTES
Se usan los paquetes de tablas, TikZ, natbib, babel y fuentes Times de LaTeX.
Las fuentes son las incluidas en la distribucion TeX.
Un paquete ausente se identifica en el primer mensaje
"LaTeX Error: File ... not found".

OVERLEAF
Importar las fuentes y seleccionar pdfLaTeX. Como archivo principal se puede
usar informe.tex (por capitulos) o informe_texmaker.tex (independiente).

PORTADA Y FORMATO
Tres integrantes, institucion, docente, fecha y Tecnologias emergentes.
Carta; margenes de 2,54 cm; 12 puntos; fuente compatible con Times;
interlineado doble; sangria de 1,27 cm; numeracion superior derecha.
Citas de autor y ano y referencias con sangria francesa.
