PORTADA
Editar datos_academicos.tex: tres integrantes, institucion, docente y fecha.
La asignatura es Tecnologias emergentes.

TEXMAKER CON EL COMANDO LATEX
1. Abrir informe.tex. Conservar chapters/, referencias.tex y
   datos_academicos.tex junto al archivo principal.
2. En Opciones > Configurar Texmaker > Comandos, establecer PdfLaTeX como:
   latex -interaction=nonstopmode -synctex=1 %.tex
3. En Compilacion rapida, seleccionar PdfLaTeX + Ver PDF.
4. Ejecutar la compilacion rapida tres veces la primera vez.
5. Abrir informe.pdf. No se necesita la secuencia DVI/PS.

Aunque el boton se llame PdfLaTeX, el comando configurado utiliza latex.
La plantilla activa la salida PDF cuando latex usa el motor pdfTeX de TeX Live.
Si esta instalado pdflatex, tambien puede usarse directamente.

TERMINAL SIN LATEXMK NI XELATEX
Desde esta carpeta:
    mkdir -p build
    latex -interaction=nonstopmode -halt-on-error -output-directory=build informe.tex
Ejecutar el ultimo comando tres veces en total para completar las referencias.
Resultado: build/informe.pdf

CON MAKE
    make pdf
Make utiliza pdflatex si existe y, en otro caso, latex.
Para elegirlo explicitamente:
    make COMPILADOR=latex pdf

OVERLEAF
Importar el ZIP, seleccionar informe.tex y usar pdfLaTeX.
La plantilla tambien conserva compatibilidad con XeLaTeX.

PAQUETES
La distribucion TeX debe incluir los paquetes de tablas, TikZ, natbib y fuentes
Times de LaTeX. La compilacion PDF con latex o pdflatex no carga fontspec ni
polyglossia y no requiere fuentes instaladas en el sistema operativo.
En Gentoo, un paquete ausente se identifica en el primer mensaje
"LaTeX Error: File ... not found".

FORMATO
Carta; margenes de 2,54 cm; cuerpo de 12 puntos; fuente compatible con Times;
interlineado doble; sangria de 1,27 cm; numeracion superior derecha.
Citas de autor y ano y referencias con sangria francesa.
